# v1.7.0 - The demo stopped pretending

> Image2Colors.com - release notes - 2026-08-04

The old sample image did its job.

Technically.

It showed colors. It loaded fast. It gave us something to click.

But it did not feel like the product.

v1.7.0 fixes exactly that kind of drift: what people see first, what dark mode feels like after 10 seconds, and what CI is allowed to ignore.

---

## What you notice (if you use the app)

The sample experience is new.

Load Sample now opens a richer ocean-style SVG demo image, built to show gradients, contrast shifts, and layered color ranges that are closer to real extraction scenarios.

Dark mode also feels tighter:

- mode cards hover with a clearer surface change
- selected mode cards use a unified selected token path
- the app icon toggle hover is more visible on dark backgrounds
- upload preview thumb is now circular, not squared-off

No new workflow to learn. Same flow. Better first impression, cleaner theme behavior.

---

## What actually changed

Three practical moves, one release.

**1. Demo assets were rebuilt, not just renamed.**  
`assets/colorpicker_demo.svg` became versioned assets (`-v1`, `-v2`), the older `colorpicker_demo2.svg` was removed, and a new ocean generator script (`scripts/gen_ocean.py`) was added for reproducible sample-art generation.

**2. Dark-mode tokens were tightened where users actually hover.**  
`--palette-app-icon-toggle-bg-hover` was raised for visibility, a dedicated `--palette-std-btn-hover-bg` path was introduced for dark hover surfaces, and mode selection now maps to explicit `--choice-mode-selected-*` tokens instead of piggybacking on natural-mode styling.

**3. UI regressions got a harder gate.**  
Canvas/snackbar regression tests now require tracked fixtures from `tests/fixtures/example-fotos` and fail fast if assets are missing. On top of that, a new `tests/ui/style-references.spec.ts` guard checks class/token drift (static + runtime smoke), and CI runs it as part of the release path.

The release tag then aligns app versioning to `1.7.0`.

If you maintain theme-heavy UI: lock visual tokens and test references together. Isolated color tweaks are cheap. Silent drift is not.

Small on paper. Noticeable in use.
